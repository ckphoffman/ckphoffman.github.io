# Douyin Self Archive

一个 Chrome Manifest V3 扩展骨架，用来在你已登录、且能正常观看作品的抖音网页上，手动备份当前页面暴露出来的媒体链接。

## 使用方式

1. 打开 `chrome://extensions`。
2. 开启右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择这个目录：`<this folder>`。
4. 登录抖音网页版，打开或刷新你自己的私密作品详情页。
5. 先让作品播放几秒，让扩展捕捉到媒体请求，再点扩展图标里的「重新扫描」。
6. 选择「下载最佳候选」或单独下载列表里的视频候选。

## 说明

- 这个扩展只使用当前浏览器登录状态下已经能访问的页面和媒体请求。
- 它不会绕过登录、破解 DRM、下载他人私密作品、批量规避平台限制或去除水印。
- 如果只看到 `blob`、`HLS` 或「片段」候选，先继续播放几秒后重新扫描。部分页面只提供流式播放列表或分片，这个最小版本不会合并分片。
- 媒体链接可能有时效，建议发现后立即下载。

## 文件结构

- `manifest.json`: Chrome 扩展声明。
- `src/content.js`: 从抖音页面 DOM、Performance entries 和内嵌 JSON 中收集媒体候选。
- `src/background.js`: 记录当前标签页媒体请求，并调用 Chrome 下载。
- `popup.html`, `src/popup.js`, `src/popup.css`: 扩展弹窗界面。
