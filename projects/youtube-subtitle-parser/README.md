# YouTube Subtitle Word Parser

一个浏览器插件，用于解析YouTube视频的英语字幕，提取单词并记录出现位置。

## 功能特点

- ✅ **字幕解析**: 自动获取YouTube视频的英语字幕（非自动生成优先）
- ✅ **词形还原**: 将单词还原为原型（例如：am/is/are → be，worked/working → work）
- ✅ **本地存储**: 使用IndexedDB在本地存储所有数据
- ✅ **位置记录**: 记录每个单词出现的视频、时间点和句子
- ✅ **快速跳转**: 点击单词可直接跳转到视频的相应位置
- ✅ **智能搜索**: 支持单词搜索和多种排序方式
- ✅ **统计信息**: 显示总单词数、出现次数、视频数等统计

## 安装方法

### 1. 添加图标（必需）

在安装插件前，需要先添加图标文件。在 `icons/` 目录下添加以下三个图标文件：

- `icon16.png` (16x16 像素)
- `icon48.png` (48x48 像素)
- `icon128.png` (128x128 像素)

你可以使用任何图标设计工具创建这些图标，或从网上下载合适的图标。

### 2. 在Chrome/Edge中安装

1. 打开Chrome或Edge浏览器
2. 访问扩展程序页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `youtube-subtitle-parser` 文件夹
6. 安装完成！

## 使用方法

### 1. 解析字幕

1. 打开任意YouTube视频页面
2. 等待页面加载完成
3. 在视频下方找到"解析字幕"按钮（蓝色按钮）
4. 点击按钮，插件会自动：
   - 获取视频的英语字幕
   - 提取所有单词并还原词形
   - 保存到本地数据库
5. 解析完成后会显示成功通知

### 2. 查看单词

1. 点击浏览器工具栏的插件图标
2. 在弹出窗口中查看：
   - 统计信息（单词数、出现次数、视频数）
   - 所有收集的单词列表
3. 使用搜索框查找特定单词
4. 选择不同的排序方式：
   - 按频率排序（默认）
   - 按字母排序
   - 按最近使用排序

### 3. 查看详情并跳转

1. 在单词列表中点击任意单词
2. 查看单词的详细信息：
   - 总出现次数
   - 出现在多少个视频中
   - 所有出现的位置（视频、时间点、句子）
3. 点击任意出现记录，自动跳转到该视频的相应时间点

### 4. 管理数据

- **刷新**: 点击"刷新"按钮重新加载数据
- **清空**: 点击"清空数据"按钮删除所有收集的数据

## 技术特点

### 词形还原 (Lemmatization)

插件使用自定义的词形还原算法，支持：

- **不规则动词**: am/is/are → be, went → go, took → take 等
- **不规则名词**: children → child, mice → mouse 等
- **规则变换**:
  - -ed 结尾: worked → work
  - -ing 结尾: working → work
  - -s 结尾: cats → cat
  - -ies 结尾: studies → study

### 数据存储

使用IndexedDB进行本地存储，包含两个主要表：

1. **words**: 存储单词信息
   - 单词原型 (lemma)
   - 出现次数 (count)
   - 出现的视频列表

2. **occurrences**: 存储每次出现的详细记录
   - 视频ID和标题
   - 时间戳
   - 完整句子
   - 原始单词形式

## 注意事项

1. **字幕要求**:
   - 视频必须有英语字幕
   - 优先使用上传的字幕（非自动生成）
   - 如果只有自动生成的字幕也可以使用

2. **隐私保护**:
   - 所有数据存储在本地（IndexedDB）
   - 不会上传任何数据到服务器
   - 不会跟踪用户行为

3. **性能**:
   - 解析字幕可能需要几秒钟
   - 建议不要同时解析多个视频
   - 数据量大时搜索可能稍慢

## 常见问题

### Q: 为什么没有找到字幕？
A: 可能的原因：
- 视频没有英语字幕
- 字幕还未加载完成，请稍后再试
- YouTube API发生变化，请联系开发者

### Q: 为什么有些单词还原不正确？
A: 插件使用基于规则的词形还原，对于一些不常见的不规则单词可能不够准确。如需更高精度，可以考虑集成专业的NLP库。

### Q: 如何备份数据？
A: 当前版本不支持导出功能。数据存储在浏览器的IndexedDB中。如需备份，建议使用浏览器的数据导出功能。

### Q: 可以用于其他语言吗？
A: 当前版本只支持英语。词形还原功能是专门为英语设计的。
