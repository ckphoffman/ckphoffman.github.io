# 图标文件

在加载插件之前，你需要在这个目录下添加三个图标文件：

## 需要的文件

1. **icon16.png** - 16x16 像素
2. **icon48.png** - 48x48 像素
3. **icon128.png** - 128x128 像素

## 获取图标的方法

### 方法1: 在线图标生成器
访问以下网站，上传或设计图标，然后导出不同尺寸：
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
- https://www.iconarchive.com/

### 方法2: 使用Photoshop/GIMP
1. 创建一个正方形画布
2. 设计你的图标
3. 导出为三个不同尺寸的PNG文件

### 方法3: 使用在线工具调整尺寸
如果你已有一个图标：
1. 访问 https://www.simpleimageresizer.com/
2. 上传图标
3. 分别导出为 16x16, 48x48, 128x128

## 图标设计建议

- **主题**: 书本、单词、字幕相关的图标
- **颜色**: 建议使用蓝色或紫色主题（与popup界面配色一致）
- **风格**: 简洁、现代
- **背景**: 可以是透明背景或纯色背景

## 临时解决方案

如果你想快速测试插件，可以使用任何PNG图片作为占位符（确保是正方形）。

## 示例搜索关键词

在图标网站搜索时可以使用这些关键词：
- subtitle
- caption
- book
- dictionary
- words
- text
- youtube

---

添加完图标后，请确保文件名完全匹配（包括大小写和扩展名）。
