# 安装指南

## 快速开始

### 步骤1: 准备图标

在 `icons/` 目录下添加三个PNG图标文件：
- icon16.png (16x16像素)
- icon48.png (48x48像素)
- icon128.png (128x128像素)

**临时方案**: 如果你想快速测试，可以使用以下命令创建简单的占位图标（需要安装ImageMagick）：

```bash
# macOS安装ImageMagick
brew install imagemagick

# 创建占位图标
cd icons
convert -size 16x16 xc:#667eea icon16.png
convert -size 48x48 xc:#667eea icon48.png
convert -size 128x128 xc:#667eea icon128.png
```

或者从网上下载任意PNG图片，调整为对应尺寸即可。

### 步骤2: 加载插件

#### Chrome浏览器:
1. 打开 `chrome://extensions/`
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `youtube-subtitle-parser` 文件夹
5. 完成！

#### Edge浏览器:
1. 打开 `edge://extensions/`
2. 开启左下角的"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择 `youtube-subtitle-parser` 文件夹
5. 完成！

### 步骤3: 测试插件

1. 访问任意YouTube视频，例如: https://www.youtube.com/watch?v=dQw4w9WgXcQ
2. 等待页面完全加载（约2-3秒）
3. 在视频下方应该能看到蓝色的"解析字幕"按钮
4. 点击按钮，等待解析完成
5. 点击浏览器工具栏的插件图标，查看收集的单词

## 检查清单

安装后请检查：

- [ ] 扩展程序页面显示插件已启用
- [ ] YouTube视频页面能看到"解析字幕"按钮
- [ ] 点击按钮后能成功解析字幕
- [ ] 点击插件图标能打开popup窗口
- [ ] popup窗口能显示单词列表
- [ ] 点击单词能查看详情
- [ ] 点击出现记录能跳转到视频

## 常见安装问题

### 问题1: 无法加载插件
**错误信息**: "清单文件缺失或无法读取"

**解决方案**:
- 确保选择的是包含 `manifest.json` 的文件夹
- 检查文件权限，确保浏览器有读取权限

### 问题2: 插件图标不显示
**原因**: 缺少图标文件

**解决方案**:
- 在 `icons/` 目录下添加所需的三个PNG文件
- 重新加载插件

### 问题3: 在YouTube页面看不到"解析字幕"按钮
**可能原因**:
- 页面还未完全加载，等待几秒钟
- 插件未成功注入，检查控制台是否有错误
- 尝试刷新页面

**调试方法**:
1. 在YouTube页面按 F12 打开开发者工具
2. 切换到 Console 标签
3. 查看是否有 "YouTube Subtitle Parser loaded" 日志
4. 如果有错误信息，请检查相应文件

### 问题4: 解析字幕失败
**可能原因**:
- 视频没有英语字幕
- 网络问题导致无法获取字幕
- YouTube API变化

**解决方案**:
- 尝试其他有字幕的视频
- 打开开发者工具查看具体错误信息
- 检查网络连接

## 卸载插件

如果需要卸载：
1. 打开扩展程序页面
2. 找到 "YouTube Subtitle Word Parser"
3. 点击"移除"按钮
4. 确认删除

**注意**: 卸载插件后，IndexedDB中的数据可能会被保留。如需完全清理：
1. 在卸载前，点击popup中的"清空数据"按钮
2. 或在浏览器设置中清除网站数据

## 更新插件

如果你修改了插件代码：
1. 在扩展程序页面找到该插件
2. 点击刷新图标（圆形箭头）
3. 重新加载相关的YouTube页面

2. 检查浏览器控制台的错误信息
