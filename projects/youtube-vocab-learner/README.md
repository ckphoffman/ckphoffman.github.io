# 英语学习助手

这是一个帮助学习英语的工具，通过Chrome插件读取YouTube视频字幕，并提供单词统计和管理功能。

## 项目结构

- `extension/`: Chrome插件，用于读取YouTube视频字幕
- `server/`: 本地API服务器和SQLite数据库
- `web/`: 前端网站，使用React + Vite + Tailwind CSS

## 功能

1. 读取YouTube视频的字幕（仅读取上传字幕，不读取自动生成字幕）
2. 浏览和管理插件收集的视频及字幕内容
3. 统计观看过的YouTube视频字幕中的所有单词
   - 单个视频重复播放单词出现次数不会重复增长
   - 查看包含特定单词的所有YouTube视频字幕句子（单词高亮）
   - 按不同视频分类
   - 网页嵌入YouTube视频播放器，点击字幕句子直接跳转到对应位置播放
   - 单词收藏功能
   - 筛选功能：按出现次数排序、按添加日期排序、按字母顺序排序

## 安装和使用

1. 安装Chrome插件
2. 启动本地服务器
3. 访问前端网站

详细说明请参考各目录下的README文件。
